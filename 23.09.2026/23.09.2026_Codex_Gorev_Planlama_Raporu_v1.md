# 1. Yürütme sözleşmesi

Bu plan kaynak rapordaki PLAN\_AND\_DOCUMENT sınırını korur. Ürün çıkarımı yeniden başlatılmaz. P1 ve P2 bağımsızdır. H0-H3 hazırlık katmanı, P1-01..08 ve P2-01..08 ürün aşamalarını çalıştırılabilir hale getirir; onların yerine geçmez.

| Kural | Uygulama |
| --- | --- |
| P1 | Reconfigurable Measurement & Perception Workbench |
| P2 | Industrial Electronics Design & Verification Blueprint |
| Asıl kopya | Mühendislik varlıkları 002-Proje Çıktıları altındaki ilgili ürün kökünde. |
| R/O/E | R=referans, O=üretilen varlık, E=çalıştırma/doğrulama kanıtı. |
| State | PLANNED -> DRAFT -> IMPLEMENTED -> VERIFIED |
| PASS | NOT\_RUN hiçbir durumda PASS değildir. |
| Karar izolasyonu | OPEN\_DECISION yalnız bağımlı görevi BLOCKED yapar. |
| Canlı kök | Doğrulanmadan uzak klasöre yazılmaz; gerekirse staging. |

# 2. Minimum görev sırası

H0 -> H1 -> H2 -> H3 -> P1-01..03 / P2-01..02 -> yalnız READY uygulama aşamaları -> gerçek doğrulama/evidence -> handoff/docs.

Her Codex paketi tek ana teslimata, input/output yollarına, depends\_on, decision\_refs, allowed\_write\_scope ve acceptance\_check alanlarına sahip olmalıdır.
